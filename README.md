## 📌 Overview

A modern, responsive, cyber-themed personal portfolio website built to showcase offensive security tools, full-stack software development projects, technical certifications, and skillsets. Features an interactive terminal loader, responsive grid layouts, dynamic project filtering, and a direct contact form powered by EmailJS.

---

## ✨ Key Highlights

- **💻 Cyber Aesthetics:** Dark-mode cybernetic styling, custom typography, and dynamic canvas effects.
- **📱 Responsive Layout:** Mobile-first architecture optimized for all viewport sizes (smartphones, tablets, desktops).
- **📂 Project Showcase:** Filterable cards highlighting software engineering, digital forensics, and security testing projects.
- **📩 Real-time Contact:** Interactive inquiry form sending messages directly via EmailJS API.

## 🚀 Local Preview

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pradeep5250/portfolio.git
   cd portfolio
   ```

2. **Open in browser:**
   Double-click `index.html` or run with any local HTTP server:
   ```bash
   # Python HTTP server
   python -m http.server 8000
   ```
   Navigate to `http://localhost:8000`.
